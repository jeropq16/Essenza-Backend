# Contexto del proyecto

- Essenza es un backend de una boutique, desarrollado en C# con .NET 9.
- Mantener la estructura existente de Clean Architecture + DDD: Domain, Application, Infrastructure y Api.
- El usuario está aprendiendo. Priorizar una implementación sencilla, de nivel junior, con nombres claros, métodos cortos y explicaciones en español paso a paso.
- Introducir conceptos y patrones únicamente cuando exista una necesidad concreta; evitar abstracciones y complejidad innecesarias.
- Mantener las reglas de negocio en Domain y las dependencias de persistencia e integraciones fuera de esa capa.
- Implementar por etapas pequeñas que el usuario pueda comprender. Las propuestas de entidades todavía no son requisitos aprobados.
- Plantilla de referencia: https://essenza-culture-boutique.clar43877.chatgpt.site/#/
- La plantilla es una maqueta: precios, disponibilidad y condiciones de ejemplo no deben asumirse como reglas definitivas del negocio.
